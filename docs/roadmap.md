# Roadmap

1. Observe one small team and five first-time participants; fix confusion found in that trial.
2. Verify hosted authentication with two accounts, mobile layouts and keyboard navigation.
3. Add member removal, project deletion, retention controls and operational monitoring before broader adoption.
4. Improve conflict resolution and modularize the interface.
5. Validate whether local AI improves pitch clarity and speed; retain rules as the core fallback.
6. Add genuine GitHub integration only after repository permission, review and error handling are designed.

Events, meetups and startup programmes remain possible extensions; the current implementation focuses on hackathon preparation and delivery.
